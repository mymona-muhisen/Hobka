# موقع طلبات حبكة

موقع Astro يعمل على Cloudflare Workers (مجاناً):

- صفحات عربية وإنجليزية: الرئيسية، الطلب، حبّوك، الخصوصية، الشروط.
- الطلبات تُحفظ في قاعدة بيانات Cloudflare D1.
- صور الأطفال تُحفظ في Cloudflare KV وتُحذف تلقائياً بعد 60 يوماً.
- صفحة خاصة لكل طلب `/d/...` يرى فيها الأهل شكل طفلهم في الرسم، فيوافقون على الشبه أو يطلبون تعديلاً. القصة نفسها تبقى مفاجأة.
- لوحة إدارة على `/admin` محمية بكلمة سر.

## كل شيء يُدار من لوحة الإدارة

- **المنتجات** `/admin/products`: إضافة وتعديل وحذف الصناديق والإضافات، الأسعار والتكلفة، وصورة لكل منتج (تُصغَّر تلقائياً قبل الرفع وتظهر في الرئيسية وصفحة الطلب وصفحة حبّوك).
- **الإعدادات** `/admin/settings`: الواتساب وروابط إنستغرام وفيسبوك، نص تفاصيل الدفع، مدة الرسم والطباعة، «الأسعار نهائية»، أقصى عدد قيم، أسعار الشحن لكل محافظة (مع إخفاء محافظة)، وقيم القصة (إضافة وتعديل وترتيب وحذف).
- **أكواد الخصم** `/admin/discounts`: إضافة وتعديل وإيقاف وحذف.
- **الطلبات**: تعديل بيانات التوصيل والشحن والتكاليف، وحذف الطلب نهائياً مع صوره (للطلبات التجريبية).

الربح لكل طلب = (السعر بعد الخصم) − تكلفة المنتجات − تكاليف إضافية. الشحن لا يدخل في الربح لأنه يذهب لشركة التوصيل.
تكلفة كل منتج تُحفظ مع الطلب لحظة إنشائه، فتغيير التكلفة لاحقاً لا يغيّر ربح الطلبات القديمة.

القيم في `src/config/catalog.ts` هي البداية فقط. ما زال يُعدَّل من هناك: `site.url` عند شراء نطاق، الأعمار، مدة حفظ صور الأطفال، وأساليب الرسم.

## التخزين (خطة Cloudflare المجانية)

- صور الأطفال ورسومات الشخصية وصور المنتجات في KV: مساحة 1 GB، و1000 عملية كتابة يومياً. صور الأطفال تُحذف بعد 60 يوماً، والرسومات بعد 120 يوماً.
- الطلبات والمنتجات والإعدادات في D1: 500 MB لقاعدة البيانات. الطلب الواحد أقل من 5 KB.

## النشر أول مرة

1. **GitHub:** ارفعي هذا المجلد إلى مستودع جديد، ويفضّل أن يكون خاصاً (Private). لا ترفعي `node_modules` أو `.dev.vars`.
2. **إنشاء الموقع على Cloudflare:**
   - ادخلي **Workers & Pages** ← **Create** ← **Import a repository**، واختاري المستودع.
   - Build command: `npm run build`
   - Deploy command: `npx wrangler deploy`
   - اضغطي Deploy.
   - قاعدة البيانات D1 ومساحة الصور KV تُنشآن تلقائياً في أول نشر.
3. **كلمة سر الإدارة:**
   - من صفحة الـ Worker: **Settings** ← **Variables and Secrets** ← **Add**.
   - اختاري النوع **Secret**، والاسم `ADMIN_PASSWORD`، والقيمة كلمة سر قوية من 12 حرفاً على الأقل.
   - احفظي ثم أعيدي النشر (Deployments ← Retry).
4. **الرابط:** يظهر الموقع على `https://hobka.<اسم-حسابك>.workers.dev`، والإدارة على `/admin`.

إذا فشل الإنشاء التلقائي لـ D1 أو KV:

1. أنشئيهما يدوياً:
   - D1: من **Storage & Databases ← D1** باسم `hobka-orders`.
   - KV: من **Workers KV** بأي اسم.
2. انسخي الـ id لكل منهما.
3. أضيفي `"database_id": "..."` و `"id": "..."` في `wrangler.jsonc`.

## التشغيل على جهازك (اختياري)

```bash
npm install
npm run dev          # http://localhost:4321  (كلمة سر الإدارة المحلية في .dev.vars)
```

يحتاج Node.js 24.

## دورة الطلب

```
طلب جديد ← نرسم شخصية الطفل ← شكل الطفل جاهز للموافقة ← (طُلب تعديل على الشكل ← …) ← تمت الموافقة، بانتظار الدفع ← تم الدفع ← قيد الطباعة ← تم الشحن ← تم التسليم
```

- عند وصول طلب تجدينه في `/admin`، والعميل يراسلك برقم الطلب على واتساب.
- في صفحة الطلب ارفعي رسومات شخصية الطفل، فتصبح الحالة «شكل الطفل جاهز للموافقة».
- اضغطي «إرسال رابط شكل الطفل» فيفتح واتساب برسالة جاهزة.
- قبل إرسال تفاصيل الدفع عدّلي كلفة الشحن الفعلية من صفحة الطلب إن اختلفت، ثم اضغطي «إرسال تفاصيل الدفع»، وغيّري الحالة يدوياً حسب التقدّم.

## الخصوصية

- لا تُطلب صورة الطفل إلا بموافقة صريحة.
- الصور تُحذف تلقائياً بعد 60 يوماً، ويمكن حذفها فوراً من صفحة الطلب.
- لا توجد أدوات تتبع أو إعلانات.
